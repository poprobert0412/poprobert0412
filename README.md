## 👨‍💻 About me

I'm a software developer working mostly in **Python**, with a focus on AI, and co-founder of **[Snow Globe Solutions](https://snowglobe.ro)**.

- 💼 **Now:** part of a team developing an **AI document platform for public procurement**: expert technical documentation in, legally binding 100–200+ page documents out — **custom agentic workflows over Google Gemini** (structured JSON outputs, context caching, per-stage reasoning budgets), an automated QA stage, and formatted DOCX output — on a configuration-driven architecture. Involved from the early prototype stages, **I've completed the core implementation**: the **Python backend (FastAPI · PostgreSQL / Supabase)**, the JSON configuration architecture, the **agentic workflow layer** (model routing, structured outputs, context caching, prompt refinement over the Gemini API, plus hands-on testing of self-hosted models while evaluating options for the app), the extraction / grounding / geospatial / metadata modules and the DOCX output — plus bug fixes and the testing of the React / TypeScript frontend.
- ❄️ **Co-founder:** [Snow Globe Solutions](https://snowglobe.ro) — a web design and AI integration agency in Brașov. We meet businesses at their office or online and build websites, online stores, web and mobile apps and AI solutions that take repetitive work off their team, in Romanian, English and Hungarian. I lead the technical side, from the first client meeting to launch and ongoing support.
- 🎬 **Side project:** [Nexus Movie AI](https://nexusmovieai.com) — a bilingual movie / TV encyclopedia with semantic search and an AI assistant for what to watch, designed, built and deployed on my own.
- 🔍 **Background:** software testing (**ISTQB® CTFL**) — I like to pay attention to the smallest details.
- 📚 **Learning now:** C++ fundamentals · SQL and databases with Supabase (Coursera)

## 🚀 Featured projects

### ❄️ Snow Globe Solutions — [snowglobe.ro](https://snowglobe.ro)
Our agency's website and booking system, trilingual (RO / EN / HU). Built and run end to end.

- **Astro** static site with a **FastAPI** backend in Python · 105 pages indexed by Google · mobile PageSpeed 97–100
- **Online booking** with SMS and email verification codes, calendar invites (.ics) and a server-rendered admin panel
- **Security by design:** Argon2id passwords, CSRF protection, atomic rate limits, restrictive row-level security on the Supabase mirror
- **970+ backend tests** (pytest), end-to-end tests on Chromium, WebKit and Firefox, accessibility checks against WCAG 2.2 AA (axe)
- **Docker** on Oracle Cloud behind Caddy and Cloudflare, with a digest-pinned image and hash-locked dependencies

### 🎬 Nexus Movie AI — [nexusmovieai.com](https://nexusmovieai.com)
Bilingual (RO / EN) movie, TV and actor encyclopedia with AI features. Solo project, from database schema to production.

- **FastAPI** backend in Python (71 endpoints), LLM calls via **OpenRouter** (DeepSeek), embeddings via Hugging Face · **Next.js 16 / React 19** frontend in TypeScript
- **Semantic search inside PostgreSQL** (pgvector) — search by describing a plot, not by knowing the title
- **AI assistant on every title's page** — ask anything about that film or series
- **“What should I watch tonight?” assistant** — AI recommendations in prose, with every film it names resolved against the real catalog
- ~12,800 movies · 7,500 series · 3,400 actors, enriched and reconciled from five third-party APIs
- **Docker + GitHub Actions CI/CD** on a VPS behind Caddy and Cloudflare, with post-deploy health checks and automatic rollback
